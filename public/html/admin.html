How the optimiser works

  1. Distance matrix: road distances between all riders, pharmacies and customers (OSRM Table API, haversine × 1.35 fallback).
  2. Regret-2 insertion: orders that would lose the most by waiting are inserted first, at the cheapest (pickup, drop) position in any rider's route.
  3. Simulated annealing: random relocate / exchange / 2-opt / or-opt moves; worse solutions are sometimes accepted to escape local minima.
  4. Local-search polish: deterministic 2-opt + or-opt until no improvement.
Constraints: pickup before drop, rider capacity, cold-chain ≤ 40 min, busy riders continue from their last stop. Objective = rider time + 0.5 × Σ(priority weight × delivery time).

Benchmark vs exact optimum

Random single-rider instance in Chennai, solved exactly with Held-Karp dynamic programming (O(2ⁿ·n²) with precedence) and with the heuristic.
